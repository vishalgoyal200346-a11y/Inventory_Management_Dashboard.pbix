# 📦 Inventory Management Dashboard | Power BI

## 📊 Project Overview
This project analyzes inventory data using Microsoft Power BI to monitor stock levels, inventory valuation, product demand, and low-stock items.

## 🎯 Key Performance Indicators (KPIs)
- Total Stock
- Total Stock Value
- Total Units Sold
- Low Stock Items

## 📈 Dashboard Visualizations
- Stock by Product Category
- Stock Value by Supplier
- Stock Status Distribution
- Inventory Details Table
- Interactive Slicers for City, Category, and Stock Status

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

## 📁 Dataset
The project uses a sample inventory dataset containing 1,500 records for inventory analysis.

## 💡 Key Insights
- Monitor stock availability across categories and warehouses.
- Identify items requiring restocking.
- Analyze inventory value and units sold.
- Support data-driven inventory decisions.
